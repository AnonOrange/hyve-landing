🔎 What is Hyve Sleuth?

Hyve Sleuth is a professional OSINT (Open Source Intelligence) research launcher. It opens official public records, government databases, and third-party research tools directly in your browser — pre-filled with your subject's information wherever possible.

It works like a command center: enter a subject's details once, then launch 170+ national resources and 7 state-specific databases for all 50 states + DC with a single click. No scraping. No data collection. Nothing leaves your device.

170+ National Resources All 50 States + DC Smart URL Pre-fill Zero Install 100% Client-Side
🖥️ How to Run Hyve Sleuth

Hyve Sleuth is a browser-based application — no installation required. Choose any method below:

Method 1

Double-Click (Firefox / Edge)

Double-click index.html to open in your browser. Works in Firefox and Edge. Chrome may block the JS file — use Method 2 if the page loads blank.

✓ Easiest
Method 2

Python Server (Recommended)

Open a terminal in the Hyve Sleuth folder, then run:

python -m http.server 8080

Open http://localhost:8080 in any browser.

✓ Most Reliable
Method 3

VS Code Live Server

Install the Live Server extension in VS Code. Right-click index.html → Open with Live Server. Auto-reloads on save.

✓ Developer
Method 4

Node.js / npx serve

If Node.js is installed:

npx serve .

Opens automatically on http://localhost:3000

✓ Developer
💡
How to open a terminal in the folder: On Windows, hold Shift and right-click the Hyve Sleuth folder → "Open PowerShell window here" or "Open in Terminal". Then type the command above and press Enter.
📁
Keep all files together. The index.html, hyve-part2.js, and logo.png files must stay in the same folder. Moving them separately will break the app.
🚀 Quick Start — First Time
1

Read & Accept the Disclaimer

On first launch, a legal notice appears. Read it carefully, check the box confirming you are an authorized researcher, then click "Enter Hyve Sleuth →". This acceptance is stored locally and won't appear again unless you clear your browser data.

2

Create a Researcher Profile

The Profile Selector appears next. Pick an avatar emoji, type your name (e.g., "Agent Smith"), optionally set a PIN for security, then click "Create Profile →". Each profile stores its own subjects, notes, and findings separately. You can add more profiles later by clicking your name in the top-right header.

3

Enter Your Subject's Information

Fill in the left sidebar fields — Full Name is the only required field, but the more you fill in, the more SMART links will activate. Fields: Full Name, Date of Birth, City/County, State, Phone, Email, Username, Address, Domain/IP, VIN, and Image URL.

4

Click "Load"

The resource panel opens showing the subject banner and all available resources grouped by category. The header shows how many smart links are ready (e.g., "77 smart links ready").

5

Launch Resources

Click any resource card to open it in a new tab. Cards marked SMART open pre-filled search forms. Use ⚡ Launch All Smart (top-right) to open every pre-filled link at once, or use ⚡ Launch (N) buttons on each section header to batch-open just that category.

6

Save Your Subject

Click Save to store the subject profile for quick re-loading in future sessions. Saved subjects appear under the "Saved Subjects" section in the sidebar — click Load next to any saved subject to restore it.

All hit/miss data is saved automatically in your browser's local storage — no action needed. It persists across sessions and is tied to your researcher profile.
📝 Notes & Export
📝

Research Notes

The Research Notes textarea in the sidebar stores freeform notes for the currently loaded subject. Type your observations, then click Save Notes. Notes are saved per-subject and per-profile — switching subjects switches their notes automatically.

📄

Export Findings Report

Click 📄 Export Findings (in the sidebar or the header Export button) to download a .txt report file containing: subject info, list of all marked hits, list of all misses, and your research notes. The file is named automatically: HyveSleuth_SubjectName_timestamp.txt

👤 Researcher Profiles

Hyve Sleuth supports multiple researcher profiles — ideal for teams or investigators working multiple cases. Each profile has completely separate data: saved subjects, notes, and hit/miss findings.

💡 Pro Tips
🔍
Start with a name + state. Even without any other info, you'll unlock courts, DOC, sex offender registries, SOS, and 10+ people search sites with smart pre-fill.
⚡
Use per-section Launch buttons. Instead of "Launch All Smart" (which opens 70+ tabs), use the ⚡ Launch (N) button on each section header to open just that category — keeps your investigation organized.
💾
Save subjects before clearing. Click Save before clearing the form — Hyve Sleuth stores as many subjects as your browser's localStorage allows (typically 5–10MB).
🖼️
Image URL for face search. Find a public photo of your subject online, right-click → "Copy image address", paste it into the Image URL field, then use the Image/Face tab to run reverse image searches.
🔐
Breach + Email combo. Load an email address and go to the Breach/DW tab — DeHashed, HaveIBeenPwned, Intelligence X, and LeakCheck will all be pre-filled and ready to launch simultaneously.
📄
Export at the end of every session. The Export report captures everything — use it to document your investigation for case files or client reports.
🔧 Troubleshooting
ProblemSolution
Page loads blank / whiteChrome blocks local JS files. Use Method 2 (Python server) or open in Firefox/Edge instead.
Tabs / buttons don't workMake sure all 3 files (index.html, hyve-part2.js, logo.png) are in the same folder and you're using a local server.
Saved subjects disappearedData is in browser localStorage. Make sure you're using the same browser. Clearing browser data will erase saved subjects.
Logo doesn't appearMake sure logo.png is in the same folder as index.html.
Smart links not pre-fillingCheck that the required field for that resource is filled in (e.g., email for breach tools, VIN for vehicle tools).
External sites won't loadSome sites require you to be logged in or have an account. The tool opens them — you may need to create free accounts on some platforms.
